› new here?

Three ways to play classics on PC.

Fans have been bringing console games to PC in three ways. The catch: every project lives somewhere different, with its own install, update and save routine. Cartucho brings them all into one library.

Recomp

The original game’s code is translated to run natively on PC, with no emulation. It often comes with widescreen, higher frame rates and other upgrades.

Port

A version of the game rebuilt for PC, often from source code reconstructed by fans. It runs like any regular PC game.

Emulator

A program that imitates the console to run the original game. Cartucho launches your emulated games just like everything else.

› what you get

A real console for games that never had one.

Installs and updates itself

No more hunting for the right file on GitHub. Every update backs up whatever it replaces — your saves and settings are never touched.

Achievements where there were none

Reads achievements from recomps, Steam, GOG and emulators. Notifies you the moment you unlock one, shows how many players have it and celebrates your 100%.

All your playtime, in one place

Counts hours the way Steam does — even for games launched outside Cartucho — and shows how long each one takes to beat.

Built for the couch

Xbox, PlayStation, Nintendo and generic controllers, with an on-screen keyboard and remappable buttons. Keyboard and mouse work too.

Tells you what’s new

The radar flags games just added to the catalog and new versions of the ones you already have.

Runs on Linux too

Windows games launch on Linux through Proton or Wine, each with its own settings — no terminal required.

Make it yours

7 color palettes, a CRT filter, sound effects and custom cover art for any game.

The problem

Recomps and ports are scattered across dozens of repositories. Each has its own way to download, update and store saves — and almost none have achievements, playtime tracking or decent controller support.

The solution

A console-style launcher: one catalog, safe installs and updates, achievements and playtime for everything, and an interface you can drive entirely with a controller.

Architecture

Screen · renderer

React 19 + React Three Fiber for the 3D stage. Per-console hubs, spatial arrow-key navigation, on-screen keyboard.

⇄Typed tRPC over IPC
Main process · Electron

Catalog and radar, installer, playtime tracker, achievements service with one adapter per game, native SQLite with migrations.

⇄HTTP with on-disk cache
External sources

Recompendium (catalog), GitHub Releases (downloads), LaunchBox (artwork), Steam, IGDB and MyMemory (translation).

Challenges I solved

A 3D stage that stays light

Challenge: 20 console models on screen used too much memory, even while a game was running.

Solution: BC7-compressed textures, script-simplified models and releasing the stage while you play.

4× less video memory and about half the triangles (~1M down to ~500k).

Achievements for games that have none

Challenge: every recomp stores progress in a different format, and many don’t even ship an achievement list.

Solution: one adapter per game, plus binary readers that pull the original list straight out of Xbox 360 files (XDBF and XEX).

Unlocks detected instantly by watching the save file.

Installing without breaking anything

Challenge: downloading third-party executables and updating them without losing saves.

Solution: automatic asset selection, hash verification, a Windows Defender scan and a backup of everything that gets replaced.

Updates that never touch saves or settings.

A controller for 100% of the app

Challenge: file pickers, search and dialogs usually require a mouse and keyboard.

Solution: custom spatial navigation, an in-app keyboard and folder picker, and the Home button read in the background — on Linux, straight from the device.

From first boot to in-game without putting the controller down.

No ROMs, no piracy

Cartucho doesn’t include or download games, ROMs, BIOS files or keys. Recomps need a copy of a game you own. For consoles still on sale (Switch and Switch 2), it only shows which games have a recomp. A personal project, not affiliated with any console maker.

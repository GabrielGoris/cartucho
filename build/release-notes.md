## Cartucho 1.0.11

### Novidades

- **Tempo para zerar**: a página do jogo mostra quanto tempo leva para terminar a história, com os extras e para fazer 100%, segundo as médias informadas por jogadores no IGDB.
- **Chamar o Cartucho durante o jogo**: aperte o botão Home do controle para trazer o Cartucho para frente. O painel mostra o jogo aberto e o tempo da sessão, e tem atalhos para voltar ao jogo, ver as capturas ou fechar o jogo.
- **Capturas de tela**: aperte Select + Start durante o jogo para salvar uma captura. Elas ficam em Imagens\Cartucho, numa pasta para cada jogo, e aparecem primeiro nas imagens da página do jogo, marcadas como "SUA". Em "Mais opções" tem um atalho para abrir a pasta.

### Melhorado

- As notas e o tempo para zerar chegam assim que o Cartucho abre, sem esperar a próxima atualização.

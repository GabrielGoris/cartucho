## Cartucho 1.2.1

### Corrigido

- **Botão Home do controle**: o Cartucho agora vem para a frente com o foco certo, pronto para usar no controle sem precisar clicar com o mouse.
- **Capturas com Select + Start**: funcionam em qualquer jogo, mesmo os abertos fora do Cartucho, e capturam a tela onde o jogo está.
- **Controle com o Cartucho em segundo plano**: os botões que você aperta no jogo não mexem mais no Cartucho enquanto ele não está em foco.

### Melhorado

- **Segurar o Home funciona em qualquer jogo**: não só nos abertos pelo Cartucho. A barra "voltar para o jogo" leva de volta para o jogo de onde você veio.
